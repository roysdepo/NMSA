# Security policy

Security fixes target the latest published NMSA release and the default branch.

Do not open a public issue for an unpatched vulnerability. Use **Report a
vulnerability** in the repository's **Security** tab. Include the affected
version, platform, a minimal synthetic reproduction, expected and observed
behavior, impact, and any proposed mitigation.

Never attach a real save, account identifier, access token, private key, local
user path, or other personal data. Reports are reproduced with sanitized test
fixtures, fixed with regression coverage, and disclosed after a corrected
release is available.
